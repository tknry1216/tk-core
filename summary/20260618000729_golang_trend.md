# Go言語トレンドサマリー (2026年6月時点)

## 1. 最新バージョンと主要な変更点

### Go 1.26 (2026年2月リリース) — 最新安定版

- **`new` 組み込み関数の拡張**: `new(T)` が型だけでなく式も受け付けるようになった。`new(42)` で `*int` (値42) を直接生成可能に
- **自己参照的なジェネリクス型パラメータ**: ジェネリクス型が自身の型パラメータリストで自分自身を参照可能に。再帰的データ構造やインターフェースの実装が大幅に簡素化
- **Green Tea GC**: 実験的だったGreen Teaガベージコレクタがデフォルトで有効化
- **cgoオーバーヘッド削減**: ベースラインcgoオーバーヘッドが約30%削減
- **スタックアロケーション最適化**: コンパイラがより多くの場面でsliceバッキングストアをスタック上に割り当て可能に

### Go 1.25 (2025年8月リリース)

- **「コア型」概念の仕様からの除去**: Go 1.18で導入されたコア型の概念を仕様から削除し、型セットに基づく直接的な記述に置き換え。仕様の大幅な簡素化
- **`testing/synctest`パッケージ**: 仮想化された時間を使った並行コードのテスト用新パッケージ
- **`runtime/trace.FlightRecorder` API**: インメモリリングバッファへの軽量実行トレースキャプチャ
- **実験的JSON v2実装**: `GOEXPERIMENT=jsonv2` で利用可能な新しいJSON実装
- **実験的GC設計**: 10-40%のGCオーバーヘッド削減を実現する新しいGC設計

### Go 1.24 (2025年2月リリース)

- **ジェネリクス型エイリアス**: 型エイリアスに型パラメータを付与可能に。`type MyMap[K, V any] = map[K]V` が有効な構文に
- **SwissTableマップ実装**: ランタイムのマップ内部実装をSwissTableに変更。大規模マップで30%高速化、事前サイズ指定マップで35%高速化、イテレーションで10-60%高速化
- **`go:wasmexport`ディレクティブ**: Go関数をWebAssemblyホストにエクスポート可能に
- **`tool`ディレクティブ**: `go.mod`にツールバージョン管理を直接統合
- **外部キャッシュ (`GOCACHEPROG`)**: ストリーミングJSON Linesによる細粒度キャッシングプロトコル

## 2. ジェネリクスの進化

ジェネリクスはGo 1.18での導入以来、継続的に成熟している。

| バージョン | ジェネリクス関連の変更 |
|---|---|
| Go 1.22 | `for i := range N` (整数のrange) |
| Go 1.23 | range-over-func が正式な言語機能に昇格。`iter`パッケージ新設 |
| Go 1.24 | ジェネリクス型エイリアス完全サポート |
| Go 1.25 | 仕様からの「コア型」削除による簡素化 |
| Go 1.26 | 自己参照的ジェネリクス型パラメータ |

### 採用状況

- 2025年時点で**新規Goプロジェクトの73%**がジェネリクスを広範に使用 (2022年は12%)
- Uber、Netflix、Googleなどの主要企業がコアライブラリをジェネリクスで全面書き換え
- 高スループットデータ処理で**25%のパフォーマンス改善**

## 3. イテレータとrange-over-func

Go 1.23で正式採用された関数イテレータは、Goのイディオムを大きく変えつつある。

```go
// 3つの標準イテレータシグネチャ
func(yield func() bool)           // ゼロ値イテレータ
func(yield func(V) bool)          // 単一値イテレータ
func(yield func(K, V) bool)       // 2値イテレータ
```

- `iter.Seq[V]` と `iter.Seq2[K, V]` が標準イテレータ型として定義
- `slices.All`, `slices.Values`, `slices.Collect`, `maps.Keys`, `maps.Values` など、イテレータ対応関数が標準ライブラリに追加

| フレームワーク | シェア | 傾向 |
|---|---|---|
| **Gin** | 48% | 増加 (2020年: 41%) |
| **Echo** | 16% | 安定 |
| **chi** | 12% | 微増 |
| **Fiber** | 11% | 急成長 (2020年登場以降) |
| gorilla/mux | 17% | 減少 (2020年: 36%) |
| Beego | 4% | 減少 |

- Go 1.22の`http.ServeMux`パターンルーティングにより、外部ルーターからの移行が進行中
- **Fiber**がExpressJSライクなAPIで急速にシェアを拡大

### ロギング

- **log/slog** (Go 1.21+標準ライブラリ): 新規プロジェクトの推奨選択肢
- **zap**, **zerolog**: 高パフォーマンスが必要な場面で人気

### クラウドネイティブ

- Kubernetes、Docker、Prometheus、Etcd、Helm、Istioなど主要CNCFプロジェクトがGoで記述
- 新興ツール: **Crossplane** (ユニバーサルコントロールプレーン)、**Cilium** (eBPFベースネットワーキング)、**OpenFaaS** (サーバーレス)
- Dockerfileリポジトリが前年比120%成長 (190万リポジトリ)

### AI/ML

- GoはAI/MLの研究・学習ではPythonに及ばないが、**プロダクションAIインフラ**でニッチを確立
- **LangChainGo**: LLM統合 (Pythonほどの充実度はない)
- **Ollama**: ローカルLLMフレームワーク (Go製)
- **Gonum**, **Gorgonia**: 数値計算・グラフベース計算
- **ポリグロットアプローチ**: Pythonでモデル作成・学習、Goでプロダクションインフラが主流
