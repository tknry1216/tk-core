# Go言語トレンドサマリー (2026年5月)

## 1. Go言語の現在地

### 人気・採用状況

- **TIOBE Index**: 2025年4月時点で**第7位**（過去最高順位）
- **Stack Overflow Developer Survey**: 世界の開発者の**13.5%**、プロフェッショナル開発者の**14.4%**がGoを選好
- **JetBrains調査**: プライマリ言語としてGoを使うプロフェッショナル開発者は**約220万人**（5年前の2倍）
- **今後の採用意向**: ソフトウェア開発者の**11%**が今後12ヶ月以内にGoの採用を計画（JetBrains Language Promise Index 第4位）

### 主要ユースケース

- **クラウドネイティブ / DevOps**: Kubernetes、Docker、Terraformなどの基盤ツールがGoで構築されており、100万人以上の開発者がクラウド環境でGoを使用
- **マイクロサービス**: 高い並行処理性能とシンプルなデプロイモデルが支持される
- **CLI / インフラツール**: シングルバイナリ配布の利便性が評価される
- **AI/MLツーリング**: モデルデプロイ・高性能推論環境での採用が拡大中

## 2. 最新リリース動向

### Go 1.24 (2025年2月)

| カテゴリ | 主な変更点 |
|---|---|
| **ジェネリクス** | ジェネリック型エイリアスの完全サポート |
| **モジュール管理** | `go.mod` に `tool` ディレクティブ追加（`tools.go` ワークアラウンド不要に） |
| **WebAssembly** | `go:wasmexport` コンパイラディレクティブ追加 |
| **暗号化/セキュリティ** | TLSサーバーでEncrypted Client Hello (ECH)をサポート、ポスト量子鍵交換 `X25519MLKEM768` をデフォルト有効化 |
| **パフォーマンス** | GCポーズ時間15〜25%削減、ランタイムメモリ効率8%改善、コールドスタート高速化 |

### Go 1.25 (2025年8月)

- メジャーリリースとして安定性・パフォーマンス改善が中心

### Go 1.26 (2026年2月)

| カテゴリ | 主な変更点 |
|---|---|
| **言語仕様** | `new()` 関数が式を受け取り初期値指定が可能に |
| **GC** | 新ガベージコレクタ「Green Tea GC」がデフォルト有効化（移行期間中はオプトアウト可能） |
| **ランタイム** | cgoコールのオーバーヘッド約30%削減、64bitプラットフォームでヒープベースアドレスのランダム化 |
| **標準ライブラリ** | `ReadAll` が中間メモリ割当を削減し約2倍高速化 |
| **デバッグ** | `runtime/pprof` にリークgoroutineレポート用プロファイルタイプを実験的追加 |

### トレンドの変化

2026年のGo開発は、単純な構文や並行処理を超えて以下に焦点が移行：

- **システムオブザーバビリティ**: slog + OpenTelemetryの組み合わせが標準化
- **API標準化**: OpenAPI/gRPCベースの設計アプローチ
- **長期メンテナビリティ**: `go fix` によるレガシーコードの安全なモダナイズ

## 4. AI/LLMエコシステムの台頭

2026年はGoにおけるAI関連ツーリングの急成長が目覚ましい。Pythonがリサーチ・学習領域を支配する一方、**Goはプロダクション環境でのAIインフラ構築**で存在感を増している。

### 主要AIエージェントフレームワーク

| フレームワーク | 提供元 | 特徴 |
|---|---|---|
| **Google ADK for Go** | Google | 30以上のDBをMCP Toolbox経由でサポート |
| **Firebase Genkit** | Firebase/Google | プロダクション対応AIを最小セットアップで構築 |
| **LangChainGo** | コミュニティ | LangChainのGo実装、チェーン・エージェント・ツール統合 |
| **Eino** | - | Go向けAIフレームワーク |
| **Jetify AI SDK** | Jetify | Go向けAI開発キット |
| **Agent SDK Go** | コミュニティ | YAMLベースのエージェント設定、MCP統合 |

### MCP (Model Context Protocol) の成長

- **公式Go SDK**: MCP サーバー/クライアントをGoで構築する際の事実上の標準
- **Gopls MCP統合**: Go公式LSPサーバー (gopls) にMCPサーバー機能が実験的に搭載、AIアシスタントにGoの機能を公開可能
- **Ollama**: Goで書かれたオープンソースのローカルLLM実行ツールとして広く普及

> "2026年はMCPが「興味深い」から「不可欠」に変わる年" — Applied Go

### Goが選ばれる理由（AI分野）

- ネイティブ並行処理でリクエストを効率的に処理
- 強い型付けによる安全性
- シングルバイナリデプロイでコンテナ・エッジ環境に最適
- REST/gRPCのネイティブサポート

## 6. まとめ：2026年のGoを形作る5つのキーワード

| # | キーワード | 概要 |
|---|---|---|
