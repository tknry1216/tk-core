# Go言語トレンドレポート（2026年5月）

## 1. Go言語の市場動向・採用状況

### 開発者人口の成長

- **プライマリ言語として220万人**の開発者がGoを使用（5年前の2倍）
- セカンダリ言語を含めると**500万人以上**が利用
- TIOBE Index で**7位**（Go史上最高順位、2025年4月時点）
- GitHub上で**3番目に成長が速い言語**（2024年、Python・TypeScriptに次ぐ）

### 採用意向

- 全ソフトウェア開発者の**11%がGoの採用を計画**（今後12ヶ月以内）
- JetBrains Language Promise Indexで**4位**（TypeScript、Rust、Pythonに次ぐ）

### Go Developer Survey 2025 の主要結果

- 2025年9月実施、5,379名のGo開発者が回答
- **53%** がAIツールを毎日使用
- **70%以上** が何らかのAIアシスタントを定期利用
- ただし品質面での満足度は中程度

## 2. 言語バージョンの進化

### Go 1.24（2025年2月リリース）

| 機能 | 概要 |
|------|------|
| **ジェネリック型エイリアス** | 型エイリアスにジェネリクスパラメータが完全対応 |
| **Swiss Tables マップ実装** | マップ操作が最大**60%高速化**、CPU負荷2-3%削減 |
| **ツールディレクティブ** | `go.mod`で実行可能な依存関係をトラッキング（`tools.go`ワークアラウンド不要に） |
| **ポスト量子暗号** | X25519MLKEM768鍵交換メカニズムをデフォルトでサポート |

### Go 1.25（2025年後半リリース）

| 機能 | 概要 |
|------|------|
| **Green Tea GC（実験的）** | メモリウォール問題に対応する新しいガベージコレクタ。コンテナ化された高密度デプロイ向け |

### Go 1.26（2026年2月リリース）

| 機能 | 概要 |
|------|------|
| **Green Tea GC（デフォルト化）** | 平均GCポーズ時間が**100マイクロ秒未満**を達成 |
| **`new`関数の拡張** | `new`の引数に初期値の式を指定可能に |
| **crypto/hpke パッケージ** | RFC 9180準拠のHybrid Public Key Encryption |
| **simd/archsimd（実験的）** | `GOEXPERIMENT=simd`で有効化可能なSIMDサポート |
| **Guided Syntax Updates** | 新しい言語機能のコードベース全体への適用を支援 |
| **グラフィックスエコシステム** | 580K行以上のPure Goグラフィックス、5 GPUバックエンド、22ウィジェットのGUIツールキット |

## 3. Webフレームワーク動向

### 主要フレームワーク比較

| フレームワーク | GitHub Stars | 特徴 | ユースケース |
|--------------|-------------|------|------------|
| **Gin** | 88,000+ | 高速・拡張性・大規模コミュニティ | REST API全般 |
| **Echo** | - | `context.Context`活用・エラーハンドリングが慣用的 | REST API（Go的な設計重視） |
| **Fiber** | - | Express.jsライクなAPI・高パフォーマンス | Node.jsからの移行 |
| **Chi** | - | 標準`net/http`互換・軽量 | ミニマルなルーティング |
| **Encore.go** | - | 型安全なインフラ定義・自動生成 | フルスタック・クラウドネイティブ |

### テスト関連ライブラリ

- **Testify**：Go開発者の**27%**が利用する標準テスト拡張
- **gomock**：約**21%**が利用するインターフェースモッキングライブラリ
- **golangci-lint**：100以上のリンターを統合するオールインワンツール（CI/CD標準）

## 4. AI・エージェント開発

### GoのAIツーリングにおける台頭

GoはAIエージェント基盤として急速に存在感を高めている。主な理由：

- 並行処理モデル（goroutine）がエージェント間通信に最適
- 低レイテンシのGC（Go 1.26）がリアルタイムAI処理に適合
- 静的型付けによる堅牢なシステム構築

### 主要AIエージェントフレームワーク

| フレームワーク | 提供元 | 特徴 |
|--------------|--------|------|
| **Google ADK for Go** | Google | 30以上のDB対応MCP Toolbox、Go慣用的なAPI |
| **LangChainGo** | コミュニティ | LangChainのGo実装、チェーン・エージェント・ツール統合 |
| **Firebase Genkit** | Google | Firebase統合のAIアプリ構築 |
| **Eino** | コミュニティ | 軽量AIエージェントフレームワーク |

### MCP（Model Context Protocol）エコシステム

- **mcp-go**：高レベルAPIを提供するMCPサーバー/クライアント実装
- **mcp-golang**：標準プロトコル準拠のフレームワーク
- **gopls MCP対応**：Go公式LSPがMCPツールとしてAIアシスタントに機能を公開（実験的）

## 5. クラウドネイティブ・インフラ

### Goが支える主要プロジェクト

| プロジェクト | 役割 |
|-------------|------|
| **Kubernetes** | コンテナオーケストレーション（v1.36開発中） |
| **Crossplane** | Kubernetesをユニバーサルコントロールプレーンに拡張 |
| **Cilium** | eBPFベースのネットワーキング・オブザーバビリティ |
| **OpenFaaS** | 高速サーバーレスファンクション |
| **Terraform** | Infrastructure as Code |
| **Linkerd** | サービスメッシュ（ダウンタイム40%削減の実績あり） |

### オブザーバビリティのトレンド

- **OpenTelemetry**：テレメトリ標準化の中核
- **slog**：Go標準の構造化ロギング（モダンオブザーバビリティ対応）
- **PGO（Profile-Guided Optimization）**：実ワークロードに基づくパフォーマンス最適化
- AIアシスタントによるシグナル処理・異常検知の自動化

## 6. 2026年のGoを取り巻くキーワード

1. **AIエージェント基盤言語としての確立** — MCP、A2A対応の進展
2. **ポスト量子暗号** — Go 1.24でデフォルト有効化
3. **Green Tea GC** — リアルタイムワークロードへの対応力強化
4. **SIMD対応（実験的）** — 計算集約型処理のパフォーマンス向上
5. **型安全なインフラ定義** — Encore.go等による開発体験の進化
6. **オブザーバビリティの標準化** — slog + OpenTelemetry
7. **グラフィックスエコシステムの成熟** — Pure GoでのGPUアクセラレーション
