## 各バージョンの主要変更点

### Go 1.23 (2024年8月) — イテレータ

- **Range-over-func (イテレータ)**: `for-range` ループでイテレータ関数を直接反復可能に。Go 1.22 での実験的機能から正式な言語機能に昇格
- **新パッケージ `iter`**: `iter.Seq[V]`、`iter.Seq2[K, V]` 型と `Pull`/`Pull2` 関数を提供
- **新パッケージ `unique`**: 値の正規化（インターニング）によるメモリ消費削減
- **Timer/Ticker の修正**: チャネルが非バッファ化、未使用のタイマーが即座に GC 対象に

### Go 1.24 (2025年2月) — ジェネリクス強化・セキュリティ・性能改善

- **完全なジェネリック型エイリアス**: 型エイリアスにも型パラメータを持たせることが可能に (`type MySlice[T any] = []T`)
- **Swiss Tables マップ実装**: 組み込み `map` を Swiss Tables に置換。マイクロベンチマークで最大60%高速化、アプリケーション全体で約1.5%改善
- **CPU オーバーヘッド平均2-3%削減**
- **GC インクリメンタルポーズ時間 15-25% 改善**
- **`go.mod` のツールディレクティブ**: `go get -tool` で実行ファイル依存を管理、`tools.go` ワークアラウンドが不要に
- **FIPS 140-3 ネイティブ準拠**: `GODEBUG=fips140=on|only` で Go 暗号モジュール (CMVP Certificate #5247) を有効化。ソースコード変更不要
- **新暗号パッケージ**: `crypto/mlkem`（ポスト量子 ML-KEM-768/1024）、`crypto/hkdf`、`crypto/pbkdf2`、`crypto/sha3`
- **`os.Root` 型**: ディレクトリ限定のファイルシステムアクセスでパストラバーサル攻撃を防止
- **`go:wasmexport`**: Go 関数を WebAssembly ホストにエクスポート可能に

### Go 1.25 (2025年8月) — 実験的 GC・JSON v2

- **コア型の仕様からの削除**: 型セットに対する明示的ルールに置換（仕様の簡素化、動作変更なし）
- **実験的 Green Tea GC** (`GOEXPERIMENT=greenteagc`): メモリブロック中心の新 GC 設計で GC オーバーヘッド 10-40% 削減
- **実験的 `encoding/json/v2`** (`GOEXPERIMENT=jsonv2`): デコード大幅高速化、柔軟な設定、外部型のカスタムマーシャリング
- **`testing/synctest` パッケージ**: フェイククロック付きの並行コードテスト。Go 1.24 の GOEXPERIMENT から昇格
- **コンテナ対応 GOMAXPROCS**: Linux 上で cgroup CPU 帯域制限を読み取り自動調整（`uber-go/automaxprocs` が不要に）
- **`net/http.CrossOriginProtection`**: Fetch Metadata ヘッダーによる組み込み CSRF 保護

### Go 1.26 (2026年2月) — Green Tea GC デフォルト化・言語変更

- **`new` 関数の拡張**: 初期値を指定可能に。`ptr := new(int64(300))` で2ステップパターンが不要に
- **自己参照ジェネリック型**: ジェネリック型が自身の型パラメータリストで自分自身を参照可能に。再帰的データ構造で完全な型安全性を実現
- **Green Tea GC デフォルト有効化**: Go 1.25 の実験的 GC がデフォルトコレクタに。GC オーバーヘッド 10-40% 削減。AMD64 の新世代 CPU (Ice Lake, Zen 4+) では AVX-512 で追加約10%改善
- **cgo オーバーヘッド約30%削減**: `_Psyscall` プロセッサ状態の中間ステップを排除
- **スライスのスタック割り当て**: コンパイラがより多くの状況でスライスのバッキングストアをスタックに割り当て
- **`go fix` のリライト**: Go 分析フレームワークを使用した20以上のモダナイザーアナライザーによる安全な自動コード近代化
- **`crypto/hpke`**: ハイブリッド公開鍵暗号化 (RFC 9180)、ポスト量子ハイブリッド KEM サポート
- **ポスト量子 TLS デフォルト有効**: ハイブリッド SecP256r1MLKEM768 / SecP384r1MLKEM1024 鍵交換がデフォルトで有効に
- **実験的 `simd/archsimd`** (`GOEXPERIMENT=simd`): 128/256/512ビットベクトル型と演算
- **実験的 `runtime/secret`**: 暗号コード用のセキュアメモリ消去
- **ヒープベースアドレスランダム化**: 64ビットプラットフォームでのセキュリティ強化

## パフォーマンス改善

### Green Tea ガベージコレクタ

Go 史上最も重要な GC 変更。個々のオブジェクトをスキャンしてポインタを追跡する代わりに、8 KiB の連続メモリスパンを順次スキャンし、ランダムなポインタ追跡をシーケンシャルスキャンに変換。

- **Go 1.25**: 実験的 (`GOEXPERIMENT=greenteagc`)
- **Go 1.26**: デフォルト有効
- **効果**: GC ヘビーなワークロードで GC オーバーヘッド 10-40% 削減
- **AVX-512 アクセラレーション**: Intel Ice Lake / AMD Zen 4+ CPU で追加約10%改善

### Profile-Guided Optimization (PGO)

Go 1.21 GA 以降継続的に改善中。

- **2-14% のパフォーマンス改善**
- **Uber 事例**: トップサービス全体で 24,000 CPU コア節約（約4%改善）。日次プロファイル収集による継続的 PGO パイプライン構築
- **Datadog**: 最大14%の CPU 節約

### その他のパフォーマンス改善

- **Spinbit Mutex (Go 1.24)**: 高コンテンション時に最大70%高速化
- **sync.Map リライト (Go 1.24)**: 並行ハッシュトライでランプアップ期間を排除
