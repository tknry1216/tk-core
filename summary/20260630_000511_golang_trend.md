## Go 1.26（2026年2月リリース）

### Green Tea GC がデフォルトに
Go 1.26 最大の目玉は、実験的だった **Green Tea ガベージコレクタ（GT GC）** がデフォルトで有効化されたこと。従来のオブジェクト中心の concurrent mark-and-sweep から、**メモリブロック中心のアーキテクチャ**に刷新され、キャッシュローカリティの改善・同期オーバーヘッドの削減・SIMD アクセラレーションを実現した。

- GC CPU コストが **10〜40% 削減**
- AMD64 プラットフォームではさらに約 10% の追加改善
- Google 社内で本番運用済み

### 言語仕様の変更
- **`new` 関数の拡張**: オペランドとして式を取れるようになり、初期値を直接指定可能に
- **ジェネリック型の自己参照**: ジェネリック型が自身の型パラメータリスト内で自分自身を参照可能に

### パフォーマンス改善
- **cgo オーバーヘッド約 30% 削減**
- スライスのバッキングストアがより多くの状況でスタック上に割り当て可能に

### ツールチェーン
- **`go fix` コマンドの刷新**: Go analysis framework ベースに書き直され、**24 種類のモダナイザー**を搭載。古いコードを新しい書き方に安全に自動変換
- **`go mod init`** で生成される go directive の値が Go 1.26 に変更

### 新パッケージ
- `crypto/hpke` — Hybrid Public Key Encryption
- `crypto/mlkem/mlkemtest` — ML-KEM テスト支援
- `testing/cryptotest` — 暗号テストユーティリティ
- `simd/archsimd`（実験的）— アーキテクチャ固有の SIMD 操作

## Go 1.27（2026年8月リリース予定 — RC1 公開中）

### ジェネリックメソッドの導入
Go 1.18 でジェネリクスが導入されて以来、最も待望されていた機能。**メソッド宣言で独自の型パラメータを宣言可能**になった。

- 2026年1月に Robert Griesemer が提案（[#77273](https://github.com/golang/go/issues/77273)）
- パッケージスコープのジェネリック関数でしか実現できなかった処理を、型のメソッドとして定義可能に
- 制約: インターフェースのメソッドには型パラメータを宣言できず、ジェネリックメソッドでインターフェースメソッドを実装することもできない

### SIMD サポートの拡充
- 新しい実験的 **`simd` パッケージ**: ポータブルかつベクタサイズ非依存の SIMD サポート。`Int8s`、`Float32s` 等のベクタ型を提供
- `simd/archsimd` の拡張: amd64 API の改訂、**arm64 Neon 128-bit SIMD**、**WebAssembly 128-bit SIMD** サポートを追加

### 新パッケージ
- **`uuid`** — UUID の生成・パース（標準ライブラリに追加）

### ツールチェーン改善
- **レスポンスファイル（@file）** パースのサポート（compile, link, asm, cgo, cover, pack）
- **`go mod tidy`** が重複 require ブロックを自動マージ（go 1.27 以降の go.mod 対象）

### 構造体リテラルの改善
- 構造体リテラルのキーとして、トップレベルのフィールド名だけでなく任意の有効なフィールドセレクタを使用可能に

### 関数型推論の汎用化
- ジェネリック関数を対応する関数型の変数に代入・変換するすべてのコンテキストで型推論が適用されるように
