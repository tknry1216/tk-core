# Go言語 最新トレンドレポート（2026年6月時点）

## 1. 最新リリースと主要機能

### Go 1.24（2025年2月リリース）

- **ジェネリック型エイリアス**: 型エイリアスが定義型と同様にパラメータ化可能に
- **弱参照ポインタ（Weak Pointers）**: オブジェクトを生存させないポインタの導入。GCがメモリ回収可能に
- **Swiss Tablesベースの新map実装**: Go 1.23比で最大60%高速化
- **ツール依存関係管理**: `go.mod`にtoolディレクティブ追加。従来の`tools.go`ワークアラウンドが不要に
- **testing/synctestパッケージ（実験的）**: 並行コードのテスト支援。フェイクロック上で動作するgoroutineグループ
- **testing.B.Loop**: より高速で誤りの少ないベンチマーク反復メソッド
- **FIPS 140-3準拠**: Go暗号モジュールが透過的にFIPS準拠アルゴリズムを実装
- **ポスト量子暗号**: X25519MLKEM768鍵交換メカニズムがデフォルト有効
- **Encrypted Client Hello（ECH）**: TLSサーバーでのECHサポート
- **os.Root型**: 特定ディレクトリ内でのファイルシステム操作
- **go:wasmexportディレクティブ**: WebAssemblyホストへの関数エクスポート、WASIリアクター/ライブラリとしてのビルド対応
- **全体パフォーマンス**: CPUオーバーヘッドが平均2〜3%削減

### Go 1.25（2025年8月リリース）

- **Green Tea GC（実験的）**: メモリ認識型並列マーキングアルゴリズム。GC時間を10〜40%削減。Googleで既に本番利用中
- **encoding/json/v2（実験的）**: `GOEXPERIMENT=jsonv2`フラグで利用可能。性能向上、機能追加、API問題の修正
- **コンテナ対応GOMAXPROCS**: CPUリミット下でのオーバースケジューリング削減
- **http.CrossOriginProtection**: CSRF攻撃防止の新型
- **コンテナネイティブリリース**: コンテナ環境での動作最適化

### Go 1.26（2026年2月リリース）

- **Green Tea GCがデフォルト有効化**: Go 1.25での実験期間を経て正式採用
- **runtime/secretパッケージ（実験的）**: シークレット情報を扱うコードの一時変数を安全に消去
- **Core Types概念の完全削除**: Go 1.18で導入された概念を撤廃し、ジェネリックコードの表現力向上
- **ジェネリックメソッドの承認**: GitHub issue #77273で正式に承認

## 3. Go言語の利用トレンド

### クラウドネイティブ（依然として最大の強み）

- Kubernetes、Docker、Terraform、Istio、Prometheusなど主要CNCFプロジェクトがGoで構築
- マイクロサービス、DevOpsツーリング、高性能APIが主要用途
- コンテナオーケストレーション、サービスメッシュでの圧倒的存在感

### AI/ML分野での台頭

- モデルの本番デプロイ・推論環境での採用拡大
- Go MCP SDKの登場でAIツーリング分野が急成長
- kServeなどGoベースのスケーラブルなAIデプロイメント
- 開発者の70%以上がAIアシスタントを週に複数回利用

### WebAssembly/WASI

- Go 1.24で`go:wasmexport`ディレクティブ導入
- WASI Preview 2が2025年に安定版到達
- WASI 0.3.0が2026年2月リリース（非同期サポート追加）
- TinyGoが小バイナリ向け実用的代替として継続
- WASI 1.0は2026年後半に予定

### サーバーレス・エッジコンピューティング

- Goの高速起動時間と低メモリフットプリントが活用される

## 4. コミュニティ動向と注目プロジェクト

### 2025年Go開発者サーベイ結果（7,070回答）

- **満足度**: 91%が満足、約2/3が「非常に満足」
- **個人/OSSプロジェクト利用**: 72%

- 世界で約580万人がGoを使用（CNCF推計）
- 220万人がGoを主要言語として使用
- TIOBE Index 2025年4月に過去最高の7位

### ジェネリクスの成熟

- Go 1.18導入から4年、型推論の改善で呼び出し側で`[T]`を明示する必要が減少

- `slices`、`maps`、`cmp.Ordered`パッケージが標準ライブラリに定着
- ジェネリックメソッドが2026年に正式承認（issue #77273）

### リンター・ツーリング

- **golangci-lint**: CI/CD・ローカル開発の標準リンターランナー
- Profile-Guided Optimization（PGO）: 実ワークロードに基づくパフォーマンス最適化

## まとめ

2025〜2026年のGoは、以下の3つの軸で大きく進化しています:

1. **ランタイム性能の飛躍的向上**: Green Tea GC、Swiss Tables、コンテナ最適化により、既存コードを変更せずに大幅なパフォーマンス改善が得られる
2. **AI/MLエコシステムの急速な構築**: MCP SDK公式リリース、複数のAIエージェントフレームワークの登場で、GoがAIインフラ層の主要言語に
3. **言語機能の成熟**: ジェネリクスの実用的パターン確立、ジェネリックメソッド承認、json/v2など、開発者体験が着実に改善

GoはPythonのようなAI研究用途ではなく、AIモデルの本番デプロイ・スケーラブルなインフラ構築において独自のポジションを確立しつつあります。
