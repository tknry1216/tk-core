# Go言語トレンドサマリー（2026年5月）

## 1. Go 1.26 リリース（2026年2月10日）

Go 1.26が2026年2月10日にリリースされ、言語仕様・ツールチェーン・ランタイム・標準ライブラリに多数の改善が加えられた。最新パッチは **Go 1.26.3**（2026年5月7日）。

### 言語仕様の変更

- **`new()` 関数の拡張**: `new` 関数が式を受け付けるようになり、初期値を指定可能に。従来の2ステップ（変数宣言＋アドレス取得）が `ptr := new(int64(300))` の1行で記述可能。
- **ジェネリクスの自己参照型**: ジェネリック型が自身の型パラメータリスト内で自己参照可能に。複雑なデータ構造やインターフェースの実装が簡素化された。
  ```go
  type Adder[A Adder[A]] interface {
      Add(A) A
  }
  ```

### パフォーマンス改善

- **Green Tea GC がデフォルト化**: 実験的だったGreen Teaガベージコレクタがデフォルトで有効化。GCを多用するプログラムで **10〜40%のGCオーバーヘッド削減** を実現。
- **cgo呼び出しの高速化**: cgo呼び出しのベースラインオーバーヘッドが約 **30%削減**。
- **スタックアロケーション最適化**: コンパイラがスライスのバッキングストアをスタック上に割り当てられるケースが増加。
- **ヒープアドレスのランダム化**: 64ビットプラットフォームでランタイムが起動時にヒープベースアドレスをランダム化し、セキュリティを強化。
- **JPEG処理の高速化**: JPEGエンコーダ・デコーダが新しい高速かつ高精度な実装に置換。

### 新規パッケージ・実験的機能

| パッケージ | 概要 |
|---|---|
| `crypto/hpke` | Hybrid Public Key Encryption |
| `crypto/mlkem/mlkemtest` | ML-KEM（ポスト量子暗号）テストユーティリティ |
| `testing/cryptotest` | 暗号テスト用ユーティリティ |
| `simd/archsimd`（実験的） | SIMD演算のサポート |
| `runtime/secret`（実験的） | テンポラリデータの安全な消去 |
| `runtime/pprof` goroutineleak（実験的） | リークしたgoroutineの検出プロファイル |

### ツールチェーン

- **`go fix` の刷新**: Go のモダナイザーとして再実装。コードベースを最新のイディオムやAPIに自動更新する機能を提供。

## 3. 開発者コミュニティの動向（2025 Go Developer Survey）

2025年9月に実施された公式調査（回答者5,379名）の主要結果：

- **満足度**: 91%が「満足」と回答。約2/3が「非常に満足」（過去最高）。
- **開発者の要望**:
  - ベストプラクティスの特定と適用の支援
  - 標準ライブラリの活用強化
  - 言語・ツールのモダン化
- **AI開発ツールの利用**: 大多数がAI開発ツールを使用中。ただし満足度は中程度（「非常に満足」13%、「やや満足」42%）。品質面の懸念が主因。

## 4. Goの採用が拡大している分野

### AIツーリング

Goは2026年、AIツーリングの言語として急速に台頭している。モデルのデプロイメントや高パフォーマンス推論環境での利用が増加し、企業がモデル実験からスケールでのモデル統合にシフトする中、AIパイプラインアーキテクチャでの役割が拡大。

### IoT・エッジコンピューティング

並行接続を効率的に処理できるGoの特性がIoT分野で評価され、大量のデータストリームを最小限のリソース消費で処理する需要が増大。

### クラウドネイティブ・DevOps

Kubernetes、Terraform、Docker（containerd）などGoで書かれたツールがクラウドネイティブの基盤を形成。引き続きバックエンドインフラの主要言語としての地位を維持。

## 5. まとめ

Go 1.26は「再発明」ではなく「バックエンドエンジニアが実際に感じる課題の解消」に焦点を当てたリリースであり、GCの大幅改善、cgoの高速化、言語仕様の利便性向上が実現された。エコシステムでは可観測性・API標準化・長期保守性への関心が高まっており、AIツーリングやIoTなど新しい領域でのGoの採用も加速している。
